# Opportunity Compass

You are an expert Product Designer and UX Designer.

We are designing a new B2B SaaS product called OpportunityIQ.

Do NOT start coding immediately.

First, think like a senior product designer.

Our goal is to create an application that Product Managers would genuinely enjoy using every day.

## Product

OpportunityIQ

Tagline:

Turn customer conversations into product opportunities.

## Problem

Product Managers receive customer feedback from many different places:

• Discovery calls

• Sales demos

• Customer interviews

• Pilot discussions

• CRM notes

• Support tickets

Customers rarely describe the same problem using the same words.

For example:

Customer A asks for VPN.

Customer B asks for Private Deployment.

Customer C says Security approvals block procurement.

Although these are different requests, they all represent one product opportunity: Enterprise Security & Compliance.

The goal of OpportunityIQ is NOT to summarize feedback.

The goal is to help Product Managers discover recurring product opportunities hidden across customer conversations.

AI supports the analysis.

The Product Manager always makes the final decision.

## Product Principles

• AI explains.

• PM decides.

• Calm, thoughtful interface.

• Evidence before recommendations.

• Human remains in control.

## Your task

Before building the UI:

1. Think through the ideal information architecture.

2. Design the overall user experience.

3. Decide how each screen should naturally flow into the next.

4. Recommend the best navigation.

5. Recommend visual hierarchy.

6. Recommend spacing, typography and component style.

Do not generate code yet.

Instead present your recommended product structure like a senior Product Designer.
